# GlyphDrift 🌌✨

An interactive 3D text particle web application that bridges typography and generative art, transforming static words into breathing, dynamic starfields.

---

## Overview

GlyphDrift transforms ordinary text into an immersive cosmic experience where letters dissolve, shift, and drift in real time. Built with modern web technologies, it combines real-time particle rendering, custom 3D mesh shaders, and responsive UI controls to create a fluid typographic canvas.

## ✨ Key Features

* **Generative Typography:** Instantly converts text inputs into interactive 3D particle starfields and dynamic meshes.
* **Real-Time Physics & Rendering:** Powered by React Three Fiber and Three.js to handle smooth particle scattering, mouse interaction, and drifting motion.
* **Modern Tech Stack:** Developed using a high-performance frontend architecture featuring Next.js, React, and Tailwind CSS.

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **3D & Graphics:** React Three Fiber (R3F), Three.js, Drei
* **Styling:** Tailwind CSS
